# 布局模式

## 1. protocol-workbench

来源重点：`MasterController_v1.4`。

适合：协议帧生成、上报解析、串口调试、寄存器读写工具。

```text
┌──────────────────── 自定义标题栏 ────────────────────┐
│ ┌──── 固定 535 px ────┐ │ ┌────── 可扩展 ─────────┐ │
│ │ 指令生成与分析       │ │ │ 串口参数 │ 通信日志     │ │
│ │ 上报帧分析           │ │ │          │ 数据发送     │ │
│ └──────────────────────┘ │ └────────────────────────┘ │
│ 版本 | RX | TX | 帧数 | 状态 | 复位计数              │
└───────────────────────────────────────────────────────┘
```

规则：

- 主窗口建议 1330×796，最小 1080×580。
- 左栏保持固定宽度，不随窗口拉宽；新增空间分配给右侧串口日志。
- 左侧上下模块可使用垂直 splitter；右侧串口区域内部再分“参数侧栏 + 日志/发送”。
- HEX 输入/解析结果允许纵向 resize；日志区获得主要 stretch。
- 纯串口子窗口默认约 752×796，最小 640×580。

## 2. instrument-dashboard

来源重点：`ArqMinSystem_v1.1`。

适合：连接设备、批量配置、自动流程、周期诊断、性能趋势和多节点状态。

```text
┌──────────────────── 自定义标题栏 ────────────────────┐
│ ┌──── 控制区 ≥640 ────┐ │ ┌──── 诊断区 ≥800 ──────┐ │
│ │ 连接与刷新            │ │ │ 节点实时诊断 Tab       │ │
│ │ 一键操作/配置 Tabs    │ │ │ 性能与质量 Tab         │ │
│ │ 操作日志/导出         │ │ │ 卡片、表格、趋势图      │ │
│ └──────────────────────┘ │ └────────────────────────┘ │
│ 版本 | 串口 | 协议 | 刷新状态                         │
└───────────────────────────────────────────────────────┘
```

规则：

- 主窗口建议 1680×980；若左右区域分别保留 ≥640 / ≥800 px，则窗口级最小宽度应 ≥1440 px（模板取 1460 px 为边距与 splitter handle 留余量）。
- 水平 splitter：左侧 stretch 0，右侧 stretch 1；初始尺寸约 660/1000。
- 左侧上方是连接组，中部是配置/流程 Tab，下方是固定高度日志。
- 右侧使用一级 Tab 区分“实时诊断”和“性能”；多节点再使用二级 Tab，保持对称结构。
- 诊断卡片使用 2 列 Grid；行列都设置 stretch，避免单卡尺寸漂移。

## 3. serial-console

串口资产是独立能力，不应与具体协议绑定：

- 左：串口、波特率、数据位、停止位、校验、流控、连接灯、打开/关闭、打开新串口；
- 右上：通信日志；
- 右下：发送文本、发送/清空/保存；
- 支持 ASCII/HEX RX、ASCII/HEX TX、周期发送；
- 下拉框弹出前刷新端口，COM 端口按数字排序。

## 4. 响应式原则

- 用 minimum width 防止关键区域被压垮。
- 用 fixed width 保持成熟侧栏的阅读节奏。
- 用 stretch factor 指定扩展区域，不要依赖 splitter 默认行为。
- `setChildrenCollapsible(False)`，避免用户把核心面板拖到不可恢复的 0 宽度。
- 长文本使用 selectable、word wrap 或 no wrap，应按内容类型明确选择。

## 5. 选择建议

- 主要任务是“发命令、看回复、调串口” → protocol-workbench。
- 主要任务是“连设备、配参数、跑流程、看系统状态” → instrument-dashboard。
- 只有通用串口功能 → serial-console 独立窗口。
- 同时兼有两者 → 主界面使用 dashboard，协议帧工具放独立 Tab 或子窗口，不要把所有内容平铺。
