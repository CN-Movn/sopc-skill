# sopc-skill

Custom skills for SoPC / FPGA workflows.

## Skills

- `rtl-style`: Verilog RTL coding and review style skill for Vivado/Vitis FPGA work.
- `matlab-toolkit`: MATLAB GUI upper-computer debugging/tooling skill for FPGA, SoPC, and embedded-board workflows.

## Layout

sopc-skill/
├── rtl-style/
